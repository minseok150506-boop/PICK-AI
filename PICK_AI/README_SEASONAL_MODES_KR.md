# PICK AI 이벤트 모드

## 자동 모드

설정 → 이벤트 모드 → `날짜에 따라 자동`

한국 시간(Asia/Seoul)을 기준으로:

- 4월 1일 → 만우절 모드
- 10월 9일 → 한글날 모드
- 그 외 날짜 → 기본 모드

## 수동 선택

설정에서 날짜와 관계없이 직접 선택할 수 있습니다.

- 사용 안 함
- 만우절 모드
- 한글날 모드

## 만우절 모드

UI에 가벼운 이스터에그와 장난스러운 말투를 추가합니다.

하지만 다음은 절대 장난으로 바꾸지 않습니다.

- 사실 정보
- 뉴스
- 날씨
- 가격
- 일정
- 코드
- 오류 메시지
- 보안 경고
- 사용자 데이터
- 실제 구매/결제
- 비상 상황

즉, 재미는 추가하지만 거짓 정보 모드는 아닙니다.

## 한글날 모드

한국어 질문에서는:
- 자연스럽고 또렷한 한국어 우선
- 불필요한 외래 표현 감소
- 필요한 기술 외래어는 유지
- 코드/파일명/API/제품명은 원문 그대로 보존

사용자가 영어·일본어·중국어 등 다른 언어를 요청하면 해당 언어 요청을 우선합니다.

## 확장 구조

`seasonal_modes.py`의 `MODES`와 `automatic_mode_id()`에 새 이벤트를 추가하면
크리스마스, 새해, 광복절 같은 모드도 같은 방식으로 확장할 수 있습니다.


## 자동 + 수동 전환 방식

기본값은 항상 `날짜에 따라 자동`입니다.

사용자가 설정에서 만우절/한글날/끄기를 직접 선택할 수도 있습니다.
수동 선택은 한국 시간 기준 **그날 하루만** 유지됩니다.

날짜가 바뀌면 PICK이 자동으로 `날짜에 따라 자동` 상태로 복귀합니다.

따라서:
- 평소: 기본 모드
- 4월 1일: 만우절 자동
- 10월 9일: 한글날 자동
- 사용자가 직접 선택: 오늘만 임시 변경
- 다음 날: 다시 자동 판단
