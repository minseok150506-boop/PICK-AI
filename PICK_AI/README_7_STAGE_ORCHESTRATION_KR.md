# PICK AI 7단계 질문 처리

이번 버전에서는 질문을 바로 Ollama에 보내지 않습니다.

## 1. 문맥 추적
`이거`, `그거`, `아까`, `그 파일`, `그 코드` 같은 표현이 나오면 최근 대화에서 대상을 찾습니다.

## 2. 의도 분석
질문을 다음과 같이 분류합니다.
- 일반 질문
- 코딩
- 디버깅
- 오류 해결
- 날씨
- 뉴스
- 인터넷 검색
- 번역
- 요약
- 생성/수정

## 3. 질문 재구성
원문을 보존하면서, 내부 추론용 질문에 해결된 이전 문맥을 추가합니다.

제품명, 모델명, 파일명, 오류 메시지, 코드 식별자는 함부로 바꾸지 않습니다.

## 4. 도구 선택
질문에 따라:
- 인터넷 검색
- 코딩 모델
- 장기 기억
- 일반 Ollama
를 자동 선택합니다.

## 5. 관련 기억 검색
질문과 관련 있는 장기 기억만 가져옵니다.

## 6. 답변 검증
최종 답변에서:
- Brain / Thinking / 내부 추론 표시 제거
- 반복 문단 제거
- 검색을 사용했는데 출처가 전혀 없는 경우 경고
- 코딩 답변 구조 점검
을 수행합니다.

## 7. 최종 응답
검증된 답변만 사용자에게 스트리밍합니다.

## 정말 애매할 때
최근 대화로도 대상을 특정할 수 없고 정확한 답변에 중요한 정보가 빠졌을 때만
짧은 확인 질문을 먼저 합니다.

예:
`이거 왜 안 돼`
→ 직전 코드/오류가 있으면 바로 분석
→ 관련 문맥이 전혀 없으면 오류 메시지나 파일명을 한 번만 요청
