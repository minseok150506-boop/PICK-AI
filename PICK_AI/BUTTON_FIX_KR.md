# 버튼 동작 수정

이번 버전에서는 누적되어 있던 JavaScript 이벤트 코드를 하나의 컨트롤러로 다시 작성했습니다.

수정한 버튼:
- 새 채팅
- 상단 새 채팅
- 홈 전송
- 채팅 전송
- 설정
- 모델 선택
- 설정 저장
- 인터넷 검색
- 수동 검색
- 음성 입력
- 파일/도구
- 모바일 사이드바
- 채팅 이름 변경/삭제/내보내기
- 장기 기억 추가/삭제
- 코드 복사
- 답변 복사/읽기

또한 화면에 보이지만 클릭이 막히는 문제를 막기 위해 z-index와 pointer-events도 정리했습니다.

배포 후 브라우저에서 Ctrl+F5를 반드시 한 번 눌러 이전 JavaScript 캐시를 제거하세요.
