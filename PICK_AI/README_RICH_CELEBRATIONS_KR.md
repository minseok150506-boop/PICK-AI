# PICK AI 특별한 날 자동 기념 테마

이벤트 모드는 날짜에 따라 100% 자동입니다.

특별한 날에는 단순히 상단 문구만 바뀌지 않습니다.

- 테마 강조색 변경
- 특별 기념 카드
- 배경 분위기 변화
- 날짜별 장식 애니메이션
- 해당 날에 맞는 답변 분위기
- 접근성 설정에서 애니메이션 감소 시 자동 정지

예:
- 새해: 금빛 포인트 + 축하 장식
- 삼일절/광복절: 태극 테마 + 차분한 기념 카드
- 만우절: 작은 장난/이스터에그 + 라벤더 장식
- 어린이날: 밝고 둥근 UI + 가벼운 장식
- 현충일: 움직임과 색을 절제한 추모 테마
- 한글날: 한글 문자 장식 + 한국어 중심 분위기
- 할로윈: 주황/보라 포인트 + 호박/달 장식
- 크리스마스: 겨울 테마 + 눈 장식
- 연말: 별빛과 차분한 밤 테마

중요:
테마는 UI와 표현 분위기를 바꾸지만 사실 정확성, 코딩 정확성,
검색 결과, 날씨, 뉴스, 보안 정보는 바꾸지 않습니다.
