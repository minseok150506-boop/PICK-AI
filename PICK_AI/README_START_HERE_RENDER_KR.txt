PICK AI - GitHub + Render 시작

1. ZIP을 풉니다.
2. PICK_AI 폴더 안 파일 전부를 GitHub PICK-AI 저장소 루트에 올립니다.
3. Render → New → Blueprint.
4. GitHub PICK-AI 저장소 연결.
5. render.yaml 적용.
6. PICK_ADMIN_PASSWORD 입력.
7. AI 서버가 있으면 PICK_AI_BACKEND_URL 입력.
8. 배포가 끝나면 onrender.com 주소로 접속.

자세한 설명: GITHUB_RENDER_DEPLOY_KR.md
