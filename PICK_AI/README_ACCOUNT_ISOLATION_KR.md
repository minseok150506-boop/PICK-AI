# PICK AI 사용자별 데이터 완전 분리

사용자 1이 만든 채팅/메모리/파일/학습 데이터는 사용자 2에게 보이지 않습니다.

서버는 브라우저가 보내는 user_id를 믿지 않고 항상 로그인 세션의 session["user_id"]를 사용합니다.

분리 대상:
- 채팅
- 메시지
- 첨부파일
- 장기 메모리
- 꼭 기억할 사용자 정보
- 대화 요약
- 학습 피드백
- 데이터 내보내기

꼭 기억할 정보:
- 불러줄 이름
- 기본 언어
- 선호 답변 스타일
- 주요 프로젝트
- 꼭 기억해야 할 정보

이 데이터는 account_profile_memory 테이블에서 user_id별로 분리됩니다.
