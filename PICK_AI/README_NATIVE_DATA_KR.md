# PICK 자체 AI 데이터 구조

자체 AI 엔진 안에 `pick_engine/data`를 추가했습니다.

학습 데이터의 기본 형식은 JSONL입니다.

예:
```json
{"messages":[{"role":"user","content":"질문"},{"role":"assistant","content":"검수된 정답"}]}
```

`build_dataset.py`는 데이터를 읽고, 잘못된 행을 제외하고, 중복을 제거하고,
학습 데이터와 검증 데이터로 분리합니다.

중요: 사용자별 개인 메모리/비공개 채팅은 별도 계정 데이터입니다.
사용자가 학습용으로 승인하지 않은 개인 대화를 자체 모델 학습 데이터에 자동 병합하지 않는 구조를 권장합니다.
