# PICK AI 질문 이해 강화

## 추가된 처리 순서

사용자 질문
→ 보수적인 오타/띄어쓰기 정규화
→ 질문 의도 분류
→ 코딩/오류/최신 정보/날씨/뉴스/검색 여부 판단
→ "이거/그거/아까" 같은 표현은 최근 대화와 연결
→ 검색이 필요하면 검색용 질문만 별도로 정리
→ 장기 기억 + 최근 대화 + 검색 결과 결합
→ Ollama 최종 답변

## 중요한 원칙

PICK은 사용자의 원문을 마음대로 바꾸지 않습니다.

예:
- 제품명
- 모델명
- 파일명
- 코드 변수명
- URL
- 오류 메시지

는 보존합니다.

## 질문이 짧을 때

예:
`이거 왜 안 돼`

직전 대화에 오류와 코드가 있으면 바로 그 문맥을 사용합니다.

직전 문맥도 없고 무엇을 뜻하는지 알 수 없다면 그때만
한 번의 짧은 확인 질문을 하도록 AI 프롬프트에 지시합니다.

## 질문 확인 버튼

채팅 입력창의 `✓` 버튼을 누르면 PICK이 현재 질문을 어떻게 이해했는지 볼 수 있습니다.

표시:
- 감지된 의도
- 정리된 의미
- 코딩 여부
- 인터넷 검색 필요 여부
- 오류 분석 여부
- 이전 대화 참고 여부
