# PICK AI MEMORY ULTRA

이번 버전은 메모리를 세 가지 층으로 나눕니다.

## 1. 단기 기억
현재 채팅의 최근 메시지를 그대로 사용합니다.

## 2. 대화 요약 기억
대화가 길어지면 과거 내용을 압축해서 요약합니다.
최근 메시지를 모두 프롬프트에 계속 넣지 않아도 중요한 맥락을 유지할 수 있습니다.

## 3. 장기 기억
다음 종류를 별도 저장합니다.

- profile: 사용자 프로필
- preference: 말투/스타일/선호
- project: 프로젝트 구조/제약
- decision: 이미 결정한 사항
- task: 진행 중 작업
- fact: 일반적으로 기억할 정보
- summary: 압축 기억

## 자동 기억

자동 기억은 매우 보수적으로 동작합니다.

명확한:
- 사용자 선호
- 프로젝트 정보
- 결정 사항

위주로 저장합니다.

비밀번호, API Key, 토큰, 카드 번호처럼 보이는 민감 정보는 자동 기억 대상에서 제외합니다.

## 관련 기억만 사용

모든 기억을 매번 Ollama에 넣지 않습니다.

현재 질문과의 관련도 + 중요도 + 신뢰도 + 고정 여부 + 사용 횟수를 계산해
가장 관련 있는 기억만 전달합니다.

## 메모리 화면

사이드바 → 메모리

가능한 작업:
- PICK이 기억하는 내용 확인
- 직접 기억 추가
- 종류 지정
- 중요한 기억 고정
- 기억 삭제
- 자동 기억 켜기/끄기
- 대화 자동 요약 켜기/끄기
- 프로젝트/선호/결정 기억 여부 설정
- 전체 메모리 JSON 내보내기

## 사용자별 격리

모든 메모리는 `user_id`로 분리됩니다.
다른 사용자의 메모리가 검색 결과에 섞이지 않도록 DB 쿼리 단계에서 분리합니다.

## 충돌 처리

현재 사용자의 최신 발언이 과거 기억과 충돌하면 현재 발언을 우선하도록
LLM 컨텍스트에 명시합니다.

즉 과거 기억은 절대적인 사실이 아니라 보조 문맥입니다.
