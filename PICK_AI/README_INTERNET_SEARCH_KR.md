# PICK AI 인터넷 검색

이 버전에서는 인터넷 검색을 명확하게 분리했습니다.

## 자동 검색
사용자 질문에 다음 표현이 있으면 자동 검색합니다.

- 오늘 / 현재 / 지금 / 최신 / 최근
- 뉴스 / 날씨 / 기온
- 가격 / 판매 / 재고 / 출시
- 버전 / 업데이트 / 일정
- 검색 / 찾아줘 / 확인해
- YouTube / 유튜브

설정에서 인터넷 검색을 다음 중 선택할 수 있습니다.

- 자동
- 항상
- 사용 안 함

## 검색 종류
- 일반 웹: DuckDuckGo HTML 검색
- 백과사전: 한국어 Wikipedia API
- 뉴스: Google News RSS
- 날씨: Open-Meteo
- YouTube: 공개 웹 검색 + YouTube 검색 링크

API 키는 필요하지 않습니다.

## 수동 검색
채팅 입력창의 검색 버튼을 누르면 PICK SEARCH 화면이 열립니다.
검색 결과 제목, 출처, 설명, URL을 직접 확인할 수 있습니다.

## AI 답변
검색 결과가 필요한 질문이면 검색 자료가 Ollama에 전달됩니다.
검색 실패 시 최신 사실을 확인했다고 거짓말하지 않도록 프롬프트가 구성되어 있습니다.

## 네트워크
인터넷 검색은 Synology의 PICK 웹 컨테이너가 직접 수행합니다.
따라서 MiniPC에는 Ollama만 실행하면 됩니다.

구조:

인터넷
→ Synology PICK
  → 인터넷 검색
  → MiniPC Ollama
→ 최종 답변
