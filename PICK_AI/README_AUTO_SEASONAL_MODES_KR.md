# PICK AI 자동 이벤트 모드

이 버전에서는 수동/강제 모드 선택을 완전히 제거했습니다.

모든 이벤트 모드는 한국 시간(Asia/Seoul)을 기준으로 자동 적용됩니다.

## 자동 일정

- 1월 1일 → 새해 모드
- 3월 1일 → 삼일절 모드
- 4월 1일 → 만우절 모드
- 5월 5일 → 어린이날 모드
- 6월 6일 → 현충일 모드
- 8월 15일 → 광복절 모드
- 10월 9일 → 한글날 모드
- 10월 31일 → 할로윈 모드
- 12월 25일 → 크리스마스 모드
- 12월 31일 → 연말 모드

그 외 날짜에는 기본 모드가 자동 적용됩니다.

## 중요한 점

사용자는 이벤트 모드를 강제로 바꿀 수 없습니다.
설정 화면에는 현재 자동 적용된 모드만 표시됩니다.

만우절 모드도 사실 정보를 거짓으로 바꾸지 않습니다.
날씨, 뉴스, 가격, 코드, 오류, 보안, 사용자 데이터는 항상 정확성을 우선합니다.

## 기존 기능

- 7단계 질문 오케스트레이터
- 코딩
- 인터넷 검색
- 다국어
- Google 로그인
- 딥러닝 학습 센터
- 장기 기억
- 이미지/동영상/PDF 분석
- 실시간 스트리밍
- 연한 라벤더 기본 UI

모두 그대로 유지됩니다.
