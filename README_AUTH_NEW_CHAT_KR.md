- 아이디는 중복할 수 없습니다.
- 비밀번호는 다른 사용자와 같아도 됩니다.

## 새 채팅 화면
- 로그인 직후 ChatGPT와 비슷한 새 채팅 시작 화면이 표시됩니다.
- 중앙 입력창에 내용을 입력하고 Enter 또는 전송 버튼을 누르면 새 채팅이 생성됩니다.
- 왼쪽의 `+ 새 채팅` 버튼도 정상 작동하도록 오류 처리를 추가했습니다.
